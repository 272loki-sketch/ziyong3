# 旧生图系统退役

旧 NovelAI 生图运行系统已退出当前源码；历史图片与提示词保留只读展示，不通过旧接口继续生成。

- 已删除生图设置、生成按钮、自动生成队列、网络生成及配置/缓存写入代码；旧 `/api/novelai`、`/api/novelai/generate`、`/api/novelai/cached` 接口不再提供。
- 历史图片仍通过已有地址、浏览器旧 localStorage 缓存或 `GET /api/historical-images` 只读定位。新接口只返回本地图片地址或 `src: null`，不返回旧配置、Key 或缓存私有字段，不生成图片、不写缓存。
- 完整及截断图片协议均保留为可展开的“历史图片提示”；未找到图片不会补生成。原扫描、postprocess、HTML 安全和媒体服务保留。
- 原私有配置、Key、缓存、图片文件、故事及私人素材不删除、不迁写。旧磁盘索引依赖原配置参数；参数已改变且浏览器没有旧地址时，无法凭提示词反查旧图，不增加猜测扫描。

入口为 `src/historical-images.ts`、`server/rest.ts` 和 `web/src/components/Messages.tsx`。找不到旧图时先核对既有地址、本地媒体可达性和浏览器缓存，不重建生图配置、扫描猜测或补发模型请求。历史部署/验收记录不作为当前实例状态声明。
