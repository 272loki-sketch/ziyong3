# 两种正文生成模式

Web 只有 **直出 `direct`** 与 **导演 `director`**。模式绑定提交的输入，不跟随之后的按钮状态；排队、断线重放和重 Roll 保留提交模式。默认导演。两模式均由同一个主 Agent 写正文，原始启用预设与卡资料决定写法和格式。

## 直出 direct

```text
启用资料 / 当前分支 / 已有记忆与世界生态
→ 正常文学导演 literaryDirector
→ 单主 Agent 普通文本
→ 完整作者正文与格式保存、立即交付
→ 后台共用结算
```

直出保留文学导演的岗位与 Skill 职责，不缩水为裸 API 一发。不新生成拍前生态，不运行心理画像或多角度团队审稿。作者可按需通过既有工具核查来源；研究不是必经额外模型。

## 导演 director

| 阶段 | 执行者与输出 |
| --- | --- |
| evidence | 连续性、设定/知情、生活生态三份证据报告 |
| ideas | 两个独立角度，由主作者选择使用方式 |
| writing | 主 Agent 起草 |
| review | 事实与原始预设两份审阅 |
| decision / revision | 主 Agent 决定 keep 或自行改稿 |
| finalize | 主 Agent 定稿，保存并交付原稿/格式 |

日常与关键回合使用相同 3/2/2 分工；报告允许没有意见，不强制制造冲突或改稿。专家只接实际送达的资料、有界历史和前阶段报告，原预设/待审稿按岗位完整提供；不互看同阶段报告，不接完整主作者 thinking，没有正文/定稿权限。失败报告不能显示“审阅通过”。

## 交互与权限

阶段转换需读取回执，每次生成最多一次转换。工具能力决定使用原生或文本协议，不把导演偷换为直出。剧情不进入旧 `ask` 停点、自动心理画像或逐段 `draft_append` 门禁；旧 SDK 兼容分支不是第三种 Web 模式。

工具/MCP 的真实风险授权仍有效，故事行为不是现实操作许可。主作者的资料/面板写操作延后到正文保存后的结算阶段，取消不执行。导演室对谈属于独立创作辅助，不是每拍导演流程。

## 保存、格式与恢复

- Session Tree / `rpNarrative` 是故事权威，`rpAuthorDraft` 保留完整原交付，`rp-presentation-delivery` 绑定同一正文 id 的展示。
- 原稿与原正则先显示，不能用短事实投影替换。格式来自启用原文，不设固定面板白名单、不复活关闭模块。
- 作者一次输出正文与格式，无拍后格式识别、生成、补齐模型，也无作者交付格式门槛。
- 完整交付及 pending 持久化后发 `onAuthorReady`。前台转后台整理态，可发送下一条但只排队；完整运行与共享写锁仍等后台结束。
- 领域失败/取消留下收据。新Web输入（含排队后出队及可靠协议重放）先恢复必要上一拍收据，再落树并ACK；恢复失败则拒绝本条、保留草稿。显式手动恢复与新拍前置共用来源守卫数据库恢复helper，不重写故事或重复已完成领域。旧SDK没有可靠ACK保证。作者中断半稿不冒称定稿，也不作为普通成功拍入记忆。
- 显式启用的 Veridis 只生成 source/原稿 hash 绑定的局部显示投影；结构保护不构成作者格式门槛，投影不回流任何事实/变量/记忆消费者。

先交付不代表后台变量已经更新。派生面板按匹配来源只读刷新，失败仍保留完整原稿。详细完成点与锁合同见[执行流程](PLAN-ROUND-FLOW.md#前台交付与后台完成)。

## 预算和分工

默认整拍 direct/director 为 30/60 分钟，作者最多 8/24 轮，单流保护上限 15 分钟；配置可覆盖整拍预算。触限保留未完成，不自动宣称成功。专家、世界、生态、记忆、摘要和研究各有预算；格式不额外调用模型。

岗位模型独立，保留既有 Gemini 3.7/3.8 Flash 分工，Luna 原生 6 是独立选择而非全岗位替换。NPC 与 Veridis 分别使用 `stepModels.npcParallel/veridisRewrite`，缺配置不 fallback 主演或通用恢复。连接与工具支持见 [MODEL-CONNECTIONS](MODEL-CONNECTIONS.md)。

## 共同原酒馆插件边界（v1.8.13）

保留此标题供已有链接定位，边界不局限于标题中的版本。发送前原模板/助手事件，正文保存后只整理派生扩展；候选不替换作者、不写正文。每 session/card/source 各 8 次持久受管额度，不等于作者 8/24 轮；nonce/signal/scope/source 拒绝取消与换代。安装不自动启用，已开聊不能用卡开场脚本重写故事。

后台按启用条件运行场记、世界、鲜活世界、数据库、酒馆插件/MVU 和显示润色六路；NPC 在生态路内部统一采纳，不另推进一套人物。原文件不改不等于完整酒馆兼容，见 [TAVERN-PLUGINS](TAVERN-PLUGINS.md)、[NPC](NPC-PARALLEL.md)、[Veridis](VERIDIS-REWRITE.md)。

实现入口：`src/stage/engine.ts`、`agent-turn.ts`、`agent-director.ts`、`agent-presentation.ts`。维护须同时检查[执行合同](PLAN-ROUND-FLOW.md)、[工具权限](PLAN-RP-TOOLING.md)和[测试边界](../TESTING.md)。
