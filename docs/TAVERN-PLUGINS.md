# 酒馆角色卡插件：原文件与梨园兼容宿主

梨园加载固定来源的原插件文件，并提供受限兼容宿主。它不创建第三种正文模式，原文件字节一致也不证明完整酒馆行为等价。安装和运行状态应以当前实例管理台为准。

## 使用入口

主界面工具区点击 **“酒馆插件”**（与数据库入口并列），打开独立管理弹窗。分别点击 **“打开酒馆助手原设置”**、**“打开提示词模板原设置”**，直接进入对应原插件前端；返回按钮回到插件列表，关闭按钮和遮罩关闭弹窗。主界面管理层收到 Escape 时，若已打开插件设置则先返回列表，再按 Escape 关闭管理弹窗；这些操作不新建或切换故事会话。原插件 iframe 内部焦点下的键盘事件由浏览器及原插件行为决定，不承诺跨 iframe 的 Escape 传播。桌面和手机均有入口。旧入口仍保留：设置 → **酒馆助手与提示词模板 · 原版接入**。

列表集中显示安装版本/commit、启用状态、自动更新、检查更新、更新和回退上一版。首次状态读取、原iframe初始化均有加载提示；失败显示错误并可重试，iframe载入不等于原插件就绪。管理台直接执行原插件组件，不重写上游运行文件；梨园宿主通过 CSS、DOM 与事件适配提供统一布局、中文和主题，不是对酒馆原设置页的像素级复刻，也不代表完整酒馆兼容。

### 设置页交互与语言

- 酒馆原生 `inline-drawer` 由梨园宿主接入点击、Enter/空格、展开状态与原插件监听的 `inline-drawer-toggle` 事件。酒馆助手管理页中，有直接 `legend` 且自身不是 `.TH-collapsible` 的 `.TH-fieldset`（如渲染优化/实验功能）由宿主补充折叠；酒馆助手内层 Vue `.TH-collapsible` 仍由原组件处理，不叠加第二个 click 切换。折叠适配只增补必要 DOM 属性/事件，不克隆或替换上游输入节点。
- 原助手样式所需 `mainFontSize`、主题色与灰度变量由宿主提供；设置页采用梨园的留白、分类导航、分组和昼夜主题。管理列表桌面双栏、手机单栏。
- 按原插件设置宿主页的 `document.documentElement.lang`（当前设置页声明为 `zh-CN`，不取浏览器默认语言）选择固定版本 manifest 声明的语言包；提示词模板中文文案来自原中文 JSON。翻译设置标签/说明及动态设置文案，不改控件值、故事内容、用户脚本或模板代码。
- `web/public/tavern-compat/i18n.js`、`settings-ui.js`、`settings-host.css` 属于梨园宿主文件。上游安装缓存、原 manifest/JS/CSS/settings/语言包及逐文件哈希仍保持原字节。

启用插件会执行用户信任的卡脚本/模板。管理/脚本 iframe 是受信任同源会话，不是隔离整个管理员权限的不可信JS安全沙箱。不要执行来源不明的脚本；原插件设置中的脚本启用范围仍由用户选择。脚本模型请求可能收费；不会因安装或兼容验收自动写生产故事。

## 新接入的前端合同

插件中心的 `web/src/plugins/registry.ts` 只登记静态展示信息、分类、固定宿主种类、插件依赖及可选受管模型岗位。新增条目仍须显式接线详情组件、来源管理和原设置入口；注册表不接收任意 URL、脚本或动态导入，不授予安装、模型或故事写权限，也不自动开启依赖。

原设置退出统一经过宿主保存确认：外层关闭、遮罩、Escape，以及接入的返回、重载和宿主关闭消息等待已暴露的 flush；失败保留原页，并阻止重复退出。NPC 的 flush 清除待发定时器并等待真实保存回执，不以等待 debounce 时长代替保存。详情页 Escape 返回总览，总览 Escape 关闭。此保证仅覆盖已进入宿主保存状态的修改，不包括原编辑器尚未提交的局部草稿、浏览器强制关闭或外部会话切换；缺少可确认接口时不声称已保存。新增接入须验失败留页、重复关闭、来源变化、迟到结果及手机导航；原插件实测与合成宿主测试分开报告。本地验收记录不随公开仓库发布。

## 原文件边界

- 此节的helper/template安装器固定来源仅为用户指定的两个仓库。下载固定 commit 的发行 `dist`、所需 `lib/libs/templates/i18n/locales/settings.html` 和原 logger；排除 source map，不重编、不替换字符串、不改原脚本。
- Git blob 与逐文件 SHA-256 双重核对，激活指针固定整个同版本文件集；读取时再次核对。插件原文件及运行状态存在私有 `.liyuan-tavern-plugins/`，不进入 Git 或发行包。
- 梨园维护的是导入模块、DOM、事件、提示词、变量、生命周期和网络适配。支持原文件执行不等于完整酒馆服务器、所有 API/时序或所有社区卡百分之百等价。
- 固定来源基线为酒馆助手 4.11.3、提示词模板 1.17.9；实际激活版本以管理台 commit/指纹为准。酒馆助手声明最低客户端 1.13.0；兼容参照为酒馆 1.13.4，不是 `1.1.3.4`。来源为 [N0VI028/JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner) 和 [zonde306/ST-Prompt-Template](https://github.com/zonde306/ST-Prompt-Template)，各自许可不能由梨园许可替代。

## 两模式中的位置

原启用卡/世界书/预设 → 当前分支装配与原数据库准备 → **原提示词模板/助手发送前事件处理** → 同一个 direct/director 主作者 → `rpNarrative`及完整原稿/原格式保存 → 原交付立即展示 → 后台原有账本/世界/生态/记忆与原插件派生变量整理；启用时并发Veridis独立显示润色，不新增格式生成/补齐。

启用时保留原插件需要的宏和原协议材料，不再先由旧宏清理/协议过滤删除。关掉插件后保留原有未安装行为。专家仍只报告，正文仍只有主作者可以提交；原数据库记忆流程和模型岗位不替换。

开场/没有树entryId的角色前端保留梨园兼容iframe，提供同步开场API、严格短body加载器及原Vue依赖支持。这条fallback不是另一份上游核心，MVU存在性壳不证明完整MVU原生执行。本地验收记录不随公开仓库发布。

展示使用真实分支 entryId 和 session/card 指纹定位。原助手的 HTML iframe、变量 API、原模板处理运行在兼容宿主；前端已有作者皮肤和完整格式布局继续由梨园处理。仅启用提示词模板时，先执行真实EJS模板再按HTML渲染，不伪造TavernHelper。插件错误会报告；原插件显示失败时退回不执行脚本的静态显示并提供重试。scope、entryId、HTML或插件启停变化会重新初始化，瞬时状态失败不永久缓存关闭状态，不假装旧垫片等同原插件。

## 变量、来源与恢复

插件只保存派生 metadata、设置、变量和专用书，不能回写 `mes/rpNarrative/rpAuthorDraft/thinking`。原卡/挂载书只读；原 `writeExtensionField` 保存到私有角色扩展覆盖，不改生产 PNG。

状态按 session/card、当前来源和祖先链隔离，写入有 CAS 和提交前绑定检查。内容寻址对象、不可变 base 快照保护既存子分支：后来编辑共同祖先不会污染已经冻结的子分支。重复同来源写入合并索引；备份引用的对象保留。单状态 32MiB、索引 4MiB、作用域对象 512MiB 是明确预算，触限报告而不截断故事/历史。

保存队列按绑定代次隔离：网络/CAS失败会向调用者真实抛错，下一次显式保存/flush可以重试，不以失败Promise永久封锁队列。切scope后不会自动重放旧scope未保存数据；切换发生于等待期间的旧操作拒绝。ESM导出的chat、metadata、extensionSettings与preset等可变对象保持引用身份（真正namespace/冻结或只读对象作为原子值，不强行深写），在当前绑定内原API读写与宿主持久化一致。

正文保存后的插件整理失败留 `rp-tavern-plugin-settlement:pending`，下一条输入前恢复；已处理来源去重。取消/切支拒绝迟到结果。插件自己的模板副作用属于派生扩展，不是故事事实。

## 脚本模型调用与崩溃锁恢复

脚本模型只返回`candidateOnly`候选，不写故事正文。内部运行时的每个回合固定nonce，HTTP请求在入口捕获取消signal；读完请求体、预约额度与调用前再核对scope/source、插件权限、忙碌与回合代次。旧realm、已经取消的回合、同来源重试时迟到的请求不能借用新的signal。外部脚本在主作者忙碌时拒绝调用。

每session/card/source最多8次辅助调用尝试，账本独立于故事CAS revision写入私有`model-request-budget.json`；257个以上来源不淘汰已有计数，重启、兄弟分支切换及多进程也不能清零。账本达到4MiB或损坏时拒绝而不截断。预约之后的取消/网络失败不自动退款，防止已计费请求被重复放行。持久化从v1.8.13起生效，v1.8.12内存中的历史调用无法可靠重建，不能把它描述为从未重置的历史账本。

状态保存和预算共用私有进程锁，owner记录PID、Linux starttime、boot标识、nonce。可以确认死亡或PID复用时自动回收；活着或身份不明的owner不会因为“很旧”被抢。旧版空锁超过30秒宽限且稳定核验后恢复，此策略不能证明无限暂停的旧版writer已死亡。损坏owner、symlink/陌生内容保守返回409，不递归删除；提交前核对绑定及锁所有权，释放只能释放自己的nonce。

## 自动更新与回退

自动更新默认开启，但新安装不默默启用执行。每六小时检查固定仓库；下载到候选目录，全文件复核后在**合成会话**执行初始化、EJS 发送前处理、变量/持久化和原助手 iframe 验收，并组合当前已启用的另一插件原文件。只有宿主空闲且验收成功才原子切换；忙时候选等待，失败保留当前版并显示错误。保留上一版以回退，回退也不在生成中切换。

兼容门禁覆盖所列合成场景，不是原酒馆全行为黄金对照。若未来上游新增未适配 API，候选被拒绝，不通过改上游源码绕过。

## 依赖与安装

需要 Git、curl、Playwright Chromium 及其系统库。原浏览器依赖固定版本、校验原字节；原 iframe CDN URL 由宿主映射到这些兼容依赖和同 commit logger，并非改写上游 HTML。图标/额外作者外部资源仍可能依赖网络。服务器自动处理仅允许兼容宿主及列明依赖，不承诺任意外部脚本/网络应用均能离线运行。

代理优先级：明确参数 → `LIYUAN_TAVERN_GIT_PROXY` → 私有 `network.json` → HTTPS_PROXY/HTTP_PROXY。Git 在代理连接/TLS失败时对同一固定公开仓库做一次无凭据直连重试，不关闭证书验证、不改变模型连接。通用源码不硬编码实例网关。

```bash
# 仅暂存，不绕过运行服务的空闲门禁
node scripts/install-tavern-plugins.mjs
# 只在已停服务/明确离线安装时允许激活；--enable 是显式授权
node scripts/install-tavern-plugins.mjs --activate-offline --enable
```

## 两新来源的专属Git路由

helper/template 的共享代理策略不被专属适配覆盖。两新来源使用 `server/plugin-git-network.ts`：明确参数 → 专属环境（NPC `LIYUAN_NPC_PARALLEL_GIT_PROXY`；Veridis `LIYUAN_VERIDIS_REWRITE_GIT_PROXY`，兼容旧 `LIYUAN_VERIDIS_GIT_PROXY`）→ 自己的私有 `network.json` → `LIYUAN_TAVERN_GIT_PROXY` → 旧共享网络文件 → Git HTTP(S) 环境代理。选中的 `gitProxy: ""` 为显式直连，不继续回退；缺省才回退。

两专属目录 0700/网络文件 0600，拒绝 symlink 或含凭据代理，不改旧共享设置和模型网络。检查成功只证明当次来源路径可用；下载不等于兼容或已激活，失败保留旧版、错误回执及回退。

## 源码与诊断

- 来源、浏览器运行、HTTP 和持久化：`server/tavern-plugin-*.ts`。
- 模块/事件/变量适配及原设置主题语言：`web/public/tavern-compat/`。
- 管理入口：`web/src/components/TavernPluginsManager.tsx`；MVU 原资产/概览另见 [MVU](MVU.md)。
- 设置点不动或折叠异常时核对原界面就绪、DOM 折叠类型及宿主资源版本；不要给原 Vue 折叠重复加 click，也不要替换输入节点来修布局。
- 原设置加载而正文 iframe 失败时核对 entryId/scope、原插件启用、模板处理及允许依赖；静态 fallback 不证明脚本已运行。
- 模型请求被拒绝时检查是否外部脚本抢占作者忙碌期、旧 nonce/signal、额度耗尽或来源失效，不重启清账本或借用新回合身份。
- 变量保存失败时向调用者报错并显式重试；切 scope 后不重放旧保存队列。后台 pending 按同来源收据恢复，不重写故事。

同步开场 API 只允许切换第零楼已有 swipe，已经开聊不开放脚本正文编辑。短 body 加载器保留闭合与长度保护，不把任意畸形 HTML 当完整应用。宿主的 bridge/host/i18n/settings 资源由服务动态读取，修改可影响未重启服务；维护时 HTML/dist 与服务端资源白名单必须配套，不能把“未重启”当隔离保证。
