# Agentic Research：当前使用与维护指南

研究是同一主作者的按需只读证据工具。搜索候选、已读原文和研究结论分别记录，不另设正文作者，也不自动把资料采纳为故事事实。

## 使用方式

梨园仍只有 `direct` 和 `director` 两种正文模式。研究是按需工具能力，不是第三种模式或每拍必经步骤。

- **普通直出**：已有上下文、世界书和本地资料足够时直接创作，不启动研究模型或强制联网。
- **必要核查**：主作者可用 `web_research` 找候选，随后 `web_open` 阅读实际原文；返回结果进入同一作者的下一次决策。预算是上限，不是必须用完的次数。
- **导演研究**：同一主作者可追查缺口/冲突，已读证据进入既有专家 `sources`。3证据、2角度、唯一作者、2审阅、修订和原稿先交付保持。
- **原著资料**：`canon_research`用于当前Novel Play作品事件证据；索引未命中可回退同版本全文。`corpus_research`检索当前绑定作品/文档原文并返回位置、版本和指纹。没有命中不等于原著没有。
- **证据回执**：`research_record`声明问题、核对host证据ID、记录supported/inferred/conflicted/unknown、未解问题或停止状态。出处核验不是语义蕴含证明。

已导入原文时优先本地证据。作者规划可参考公开未来事件，但这不证明角色已经知情；当前分支修改优先，研究不自动写世界书、记忆或Session Tree。

## 搜索授权与隐私

沿用既有 `webResearchMode`：`off`关闭、`manual`需要明确联网请求、`auto`允许作者按需决定。`webResearchPublicTerms`只用于用户明确批准的公开标识，不能靠作品标签自动批准私人卡名。

本地门禁保护当前祖先分支的角色身份、私人原话、原稿/格式、设定与检索材料，并在query和实际网页请求前检查凭据/联系方式。URL必须来自本轮候选或用户明确提供；缓存按会话、卡、资料、授权、作品版本和祖先来源隔离，取消/切支拒绝迟到结果。

**这不是对所有未知别名、编码、改写或当前任务中私人事项的语义匿名化保证。** 严格私人使用可选off/manual并明确公开主题；不要把私人小说全文或真实个人信息当搜索词。网页内容是不可信数据，不是系统指令或当前世界事实。

## 研究专属网络配置

未设置应用本地配置时沿用现有环境代理；不会因代理失败自动改为直连。部署者可在私有 `.liyuan-research/network.json` 显式选择路线，例如：

```json
{"version":1,"route":"direct"}
```

这是运维文件，不是模型工具参数；仅影响研究搜索与网页读取，不改变模型网络、全局代理或私人 Key。需要恢复环境路线时将 `route` 设置为 `environment`。文件只接受此版本和两种 route，非法现存配置拒绝研究；路径、符号链接与大小检查保留。私有目录/文件按 700/600 保护，并从 Git 与发行排除。

默认DuckDuckGo/Bing搜索采用每请求原生HTTPS连接，不继承SDK全局模型fetch代理；网页阅读保留公网IP pinning、证书验证、内网/元数据地址拒绝、160KB和超时限制。数据源失败时明确降级，不把摘要冒充已读原文。

## 实际模块与维护入口

| 模块 | 当前责任 |
| --- | --- |
| `src/stage/engine.ts`、`agent-turn.ts`、`agent-director.ts` | 原有主作者工具循环、资料/权限/分支守卫、既有专家来源、交付与结算 |
| `src/research/session.ts` | 每拍只读证据账本、host来源ID、问题授权、四态结论与缺口 |
| `src/tools/{web-research,agentic-research,research-scope,research-cache,research-privacy}.ts` | 统一工具、额度/复用、缓存与外发检查 |
| `src/novel-play/fulltext.ts`、`src/outline/source-research.ts` | 已绑定源文全文、精确位置与版本/指纹，不复制故事事实库 |
| `server/web-research.ts`、`web-source-reader.ts`、`web-research-network.ts` | 候选后端、安全正文读取和运维专属网络策略 |
| `src/research/agentic-loop.ts` | 保留的行为契约/参考runner与测试oracle，**不是另一个生产模型或调度器** |

原始预设、私人Skill和卡决定写法；研究不能额外生成正文。Veridis是已授权的后台显示投影，不回写原稿/事实，其目标补集和来源保护见[Veridis指南](VERIDIS-REWRITE.md)。

## 诊断与限制

1. 没有联网调用时先检查 `webResearchMode`、本轮授权、工具能力和预算；已有资料足够而不研究是正常行为。
2. 搜索空结果或来源失败时，检查查询是否过窄、URL 是否为候选或明确提供、网络路线及安全拒绝原因；不要关闭 TLS、SSRF 或隐私门禁来凑成功。
3. 只有实际 `web_open` 读取的原文才是已读证据，搜索摘要不能冒充全文。核对 host ID、位置、版本、指纹和当前祖先来源。
4. supported/inferred/conflicted/unknown 是带出处的研究记录，不是形式化语义证明；冲突和缺口要保留，角色知情另按故事来源判断。
5. 缓存失效或取消后不重用兄弟分支结果，也不自动重发可能收费的请求。用 [请求查看器](REQUEST-INSPECTOR.md) 核对实际调用和 usage，而非预览或估算。

默认免费搜索会出现空结果，复杂查询/语种/领域覆盖、长引与人物心理语义不能保证全部正确。已有官网URL和可校验本地原文更容易核对；仍需原稿/出处对照。真实生产P50/P95、大样本作品准确率和收费金额没有验证，不作性能或质量满分承诺。
