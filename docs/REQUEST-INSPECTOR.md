# 实际请求与提示词查看器

查看器用于只读核对已观测的真实请求、耗时与供应商用量，不以提示词预览冒充实发载荷，也不提供完整账单保证。逐请求列表、详情、完整消息与导出由梨园独立模块实现，不复制第三方源代码、存储或提示词。本文不描述本机 checkout、部署或验收状态。本地验收记录不随公开仓库发布。

## 入口与准确性

主界面“提示词查看器”列出当前会话、卡和合法祖先分支的请求，可按模型、阶段、状态、轮次 id 或请求 id 搜索，查看最终消息、工具、采样参数与完整 JSON，手动刷新或下载单次记录。

- 真实 SDK 调用的 `onPayload` 截获最终请求载荷，位于作者工具协议、原插件处理与采样器投影之后。原装配预览或运行后重组内容不称实发。
- 没有最终载荷时标明“只有 SDK 上下文”；没有历史记录时显示暂无，不重新生成来补记录。
- 单调时钟记录请求开始、首个文本/思考增量、结束与状态。单次耗时、首增量、端到端与并发阶段分别显示，不把并发请求耗时相加当整拍墙钟。
- token 使用供应商/SDK 返回的 usage，输入总量含缓存读取/写入，输出与 total 按回执保存为整数。缺回执，包括 SDK 默认全零空 usage，明确标缺失，不以字符估算填成精确值。供应商内部重试、账单与未公开推理用量不据此称全覆盖。
- 回合详情的逐请求清单可用请求 id 与查看器互相核对。阶段聚合表示 harness 调用覆盖，不代表供应商内部全部尝试；数据库、插件与 embedding 的实际请求另行观测。

## 数据库与旁路观测

数据库受管请求按真实运行边界区分 `database.before`（拍前召回/输入写回）和 `database.after`（拍后整理）。回合详情单列已观测次数、成功次数、已知用量与请求耗时累计；累计不是阶段墙钟。旧 `database` 记录明确未区分，不回写或猜测归类。

未执行的旧记忆召回/弧线记为 skipped；旧零耗时 success 不当召回证明。没有框架调用不代表数据库没有请求或费用，请求成功也不证明命中或实际送达，须核对作者实发载荷。观测不改变原插件字节、召回/填表协议或正文流程。

接线涵盖主作者、固定专家、拍前与领域结算、导演室/研究旁路、酒馆助手候选、数据库模型与向量请求。原 MVU 经受管通道的额外解析使用 `mvu.parse`，界面标为“MVU 变量解析”，独立于作者请求；岗位与执行边界见 [MVU](MVU.md)。

系统助手自身 SDK 多轮、媒体模型、供应商隐藏重试与未适配的额外模型直连不承诺完整捕获。向量 API 无 usage 时只记录真实请求和耗时，用量仍缺失。

## 私密与作用域

提示词可能含私人故事和资料，存于 `.liyuan/request-journal/` 的会话/卡隔离目录，POSIX 目录 0700、文件 0600。列表不带正文；详情必须属于当前会话、卡与可见祖先来源，不能凭请求 id 读取兄弟分支或其它卡。记录不包含 API 鉴权 Header；工具 schema 中正常的 `apiKey` 等字段不因过滤鉴权而被改写。

每会话/卡保留最近 100 次或 64 MiB，不静默截短单条提示词。重启后缺结束回执的记录标为中断，不永远显示运行中。下载仍是私人数据，不上传公开仓库、报告或 fixture。

REST 为授权的只读 `GET /api/request-inspector[?id=…]`。实现入口包括 `src/stage/request-journal.ts`、`server/request-inspector.ts`、`StageEngine.#observedStream`、`server/main.ts`、`server/database-plugin-http.ts`、`src/memory/embed.ts` 与 `web/src/components/RequestInspector.tsx`。

## 汇总边界

消息头优先显示整拍端到端耗时与已观测请求输出之和，逐次清单用于独立核对；旧摘要明确标为旧摘要。底部显示保留窗口内“已观测 total tokens/有回执次数”，不把有限 SDK 消息用量称为全部 Agent 总用量。SDK 上下文估计须明确标为估计，不能代替实发或账单。
