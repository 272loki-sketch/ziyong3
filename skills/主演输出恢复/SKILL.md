# 主演输出恢复

当前是在恢复已经收到但未完成的原稿，不是新剧情回合。原稿、用户输入和已确认时间地点在本轮材料中提供；由你本人接续末尾，不交给专家。

只返回 JSON `{"suffix":"紧接原稿末尾的原作者片段"}`。suffix 从原稿最后一个字符之后开始；不要重复原稿、重开当天场景、转到另一天或输出工具/准备说明。需要闭合的对白和同一作者已经实际开启的标签容器由你接续完成；按本轮原始启用材料继续尚未交付完的同一原稿，片段可以包含原作者附属格式及闭合标签，不重演已有事实。完成本轮原本尚未写完的请求后结束，不借恢复另起新的剧情回合。

恢复只针对供应商截断、宿主明确标记的暂态 stream/queue/transport timeout 或实际已开始但未闭合的结构，不检查要求的格式是否出现，不因缺少选项、状态或变量格式而重试，不另设格式名单，也不承担拍后格式补交。

结构判定只检测可从原稿 EOF 追加接续的开放结构；父容器已经闭合时，内部子标签的局部缺口不触发恢复，不把完整原稿判成半稿。不得为了修复这种缺口在末尾补标签、返回空 suffix 或改写原稿；父容器在 EOF 仍真正开放时，保留同一作者接续。

本次恢复的 JSON-only 回执合同优先于原材料的外层输出格式合同。只返回唯一 JSON 对象，不在 JSON 外输出原卡包装、说明或代码围栏；原作者格式与闭合标签只能作为 suffix 字符串内容交付。失败响应仅用于理解 validation_errors，不属于原稿，不能直接追加。不得返回裸全文替换或重写已收到的草稿。

这只是输出交付协议，不替原始预设追加文风、主角权限或剧情确认。不得在suffix里伪造已发生的承诺或改写原稿事实。

补全仍须承接本轮用户的完整明确输入，完成原稿因截断而尚未写完的同一请求；不要把补完本轮动作误判为新增剧情回合。若收到 validation_errors，上一份恢复回执没有被追加；以未变动的原稿重新交付一份完整、唯一的 suffix JSON，不要重复失败回执中的文字。
